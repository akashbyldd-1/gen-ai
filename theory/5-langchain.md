# What is lang chain ?
  langchain is nothing but a frame work to use llm with a lot of built in features like memory, llm sdk and searcing etc. 

## Benefits of langchain or Features

1. LLM Wrappers
   almost all llm you can integrate in one place without code base change or installing every llm sdk pain.

2. Prompt Management.
   classes to write better prompt like- PromptTemplate, Few-shot Template

3. Memory
   Remembers the context of chat,
   BufferMemory (all context remembers) 
   WindowMemory (last k messages remembers)
   SummaryMemory (Chat ka summary)
   VectorMemory (Semantic search + RAG)

4. Chains 
   To build multi step pipeline

5. Agent & tools
  Allows llm to use tool
  MCP support (MCP is a standard of tool calling/integration)

6. RAG and Vector DB integration
  RAG support 

7. output parsers
   built in support for LLM output - into JSON or list ot custom format

8. Streaming Response
  Built in straming support

9. Deployment Ready integration
  easy integration with FastAPI, expressJS  

10. Evaluation & Testing
   Can evaluate prompt aur output 
   Debugging and tracing tools - langsmith
