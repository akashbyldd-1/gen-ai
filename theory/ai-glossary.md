
## **AI Glossary (Beginner-Friendly)**

### **A**

* **Agent (AI Agent)**:
  A system built around an LLM that can make decisions, call tools, and handle multi-step tasks automatically. Example: A voice agent asking questions, processing answers, and storing them.

* **API (Application Programming Interface)**:
  A way for two programs to communicate. In AI, APIs let LLMs talk to external services or your server.

---

### **C**

* **Context Window**:
  The maximum amount of text an LLM can “see” at one time while generating responses.

* **Conversation Memory**:
  Ability to remember past interactions so the AI doesn’t forget what was said earlier. MCP allows external memory systems for this.

---

### **F**

* **Function Calling**:
  A feature where an LLM can call a specific function or tool, often structured like `function_name(parameters)`.

---

### **L**

* **LangChain**:
  A framework to build AI apps with features like memory, agents, and chaining multiple tools/models together.

* **LLM (Large Language Model)**:
  A deep learning model like Claude or GPT that understands and generates text.

---

### **M**

* **MCP (Model Context Protocol)**:
  An open protocol allowing LLMs to securely connect with external tools, servers, and data sources in a standardized way.

* **Memory**:
  External systems or databases used to store chat history, facts, or context for future AI interactions.

---

### **R**

* **RAG (Retrieval-Augmented Generation)**:
  Technique where AI retrieves facts from external sources before answering, so answers are more accurate.

* **Remote MCP Server**:
  Your own or third-party server with tools that follow the MCP standard, letting LLMs interact with it safely.

---

### **T**

* **Tool**:
  Any external service or API the LLM can call to get data or perform actions. MCP connects the LLM to these tools.

* **Tool Calling**:
  The process where the LLM decides to use a tool (API, DB, service) to get data or do work.

---

### **W**

* **Workflow (AI Workflow)**:
  A chain of steps where AI uses multiple tools, decisions, and reasoning to complete a complex task.

---
